| File | Use it for |
|---|---|
| `JCH_Letterhead.docx` | Writing letters in Word. Type in the page body; the letterhead repeats on every page. |
| `JCH_Letterhead.pdf` | Printing blank letterhead sheets, or sending a blank copy. A4, one page. |

**Changing a detail.** In Word, double-click the top or bottom of the page to edit the header or footer. The email, phone, LLPIN, GSTIN and address are normal text there. The blue ribbons and lines are one background picture behind the page.

## Rebuilding

The design is generated by the scripts in `build/`. Edit the `DETAILS` block in `build/make_docx.cjs`, then run from the repository root:

```bash
python3 letterheads/jch-business-solutions/build/make_art.py              # ribbons, divider, cleaned logo
node letterheads/jch-business-solutions/build/make_docx.cjs                # writes JCH_Letterhead.docx
soffice --headless --convert-to pdf --outdir letterheads/jch-business-solutions letterheads/jch-business-solutions/JCH_Letterhead.docx
```

`build/logo-source.png` is the 256 px image from `JCH_Logo.ico`. For sharper print, replace it with a larger original logo (PNG, ideally 1000 px wide or more) and rebuild.
